# Sequence Core

A dependency-free Python reference implementation for machine-learning, sequence-model, numerical.

Run with: python3 demo.py
Tests: python3 -m unittest discover -s tests -v

## Scope

实现一个仅使用 Python 标准库的 CPU 序列计算核心，提供线性层、逐步前向、梯度累积清零和截断反向传播的最小公开接口，并支持可反向传播的逐步前向会话（start_stream/step/finish_stream），逐行到达的输入得到与批量轨迹一致的输出和梯度。序列输入支持任意宽度的多特征行：Linear 接受至少两个权重时，前 d 个权重作为输入特征系数、最后一个作为循环隐状态系数，反向按输入形状返回每步 d 个输入梯度的行（d 为一时保持标量序列的既有输出类型与梯度列表形状）。截断边界必须真正生效，片段边界的隐状态按接口规则处理，参数更新与公开公式一致；实现不依赖 GPU、网络或第三方框架，数值结果可以通过小规模有限差分脚本复核。TanhSequence 还提供 checkpoint/restore 两个公开入口：checkpoint 在不修改任何状态的前提下返回仅属于当前实例的独立检查点（完整保存隐状态、已产生输出、流会话、截断配置、carry_hidden 规则以及所包装 Linear 的参数、累积梯度和成功前向缓存，且与可变数据不共享引用、可多次恢复）；restore 先校验检查点（损坏、来自其他实例或线性层宽度不兼容时抛出 ValueError 且状态不变），再原子替换当前状态并返回 None，使暂停后的继续计算与从未中断的前向轨迹逐值一致。在此之上，TanhSequence 还提供可跨同宽度实例迁移的 export_state/import_state：export_state 在不修改任何状态的前提下返回仅由字典、列表、有限数字、布尔值、字符串和 None 组成的独立状态对象（带固定整数版本，当前为 1；完整保存隐状态、输出、批量缓存或流会话、初始隐状态、截断与 carry_hidden 规则、有序边界列表、前向参数快照以及 Linear 的权重、偏置、累积梯度和最近前向缓存，无缓存或无会话以 None 表示，且与实例及其他导出结果不共享可变引用）；import_state 接受该对象、其深拷贝或 JSON 往返后的等价值，先做完整的结构与语义校验（类型或字段结构错误、版本或宽度不兼容、非有限数字、轨迹长度或边界不一致、流会话与批量缓存并存、隐状态关系违反截断规则、Linear 缓存形状错误均抛出 ValueError 且目标状态完全不变），再一次性提交并返回 None，使另一个相同宽度的 TanhSequence 从导出时刻继续 step、finish_stream 或任一 backward 入口时与源实例逐值一致，重复导入同一对象结果稳定。Linear 另提供 clip_gradients(max_norm) 显式累计梯度裁剪入口，供 CPU 训练循环在 apply_gradients 前限制一次更新的幅度：grad 全部分量与 grad_bias 视为一个整体向量，按全局 L2 范数（平方和的平方根，平方会溢出的有限分量仍按数学定义求得正确范数）与上限比较，未超限时不改梯度并返回 1.0，超限时以 max_norm/norm 同比例缩放两个梯度字段并返回该比例；max_norm 仅接受有限非负 Python int/float（允许零，零上限且范数非零时全部梯度归零并返回 0.0，零范数保持全零并返回 1.0），布尔、字符串、None、负数、NaN、无穷大、溢出整数，以及梯度含非数值/非有限值或范数溢出均抛 ValueError，且失败时 weight、bias、前向缓存、TanhSequence 全部状态与两个梯度字段保持调用前的完整值。在此之上，SigmoidSequence 作为第二种序列单元提供与 TanhSequence 完全同形的公开接口（forward/step/start_stream/finish_stream/backward/backward_with_initial_hidden/backward_with_boundaries、checkpoint/restore、export_state/import_state），沿用 Linear 前 d 个输入权重加最后一个循环权重的布局与全部截断、carry_hidden、initial_hidden、segment_starts 规则：预激活 z 为输入加权和、循环隐状态项与偏置之和，输出按 σ(z)=1/(1+exp(-z)) 计算（z 为负时改用稳定等价形式 exp(z)/(1+exp(z))，任意有限输入都不会因指数溢出失败），反向局部导数为 output*(1-output)；其导出状态的 kind 标记与 TanhSequenceState 区分（版本规则一致，当前为 1），状态字典只向同类且宽度相容的实例迁移，checkpoint 同样只在创建它的实例上恢复，非法参数、非有限结果与失败原子性规则与 TanhSequence 完全一致。在此之上，SoftplusSequence 作为第三种序列单元提供与 TanhSequence 完全同形的公开接口（forward/step/start_stream/finish_stream/backward/backward_with_initial_hidden/backward_with_boundaries、checkpoint/restore、export_state/import_state），沿用 Linear 前 d 个输入权重加最后一个循环权重的布局与全部截断、carry_hidden、initial_hidden、segment_starts 规则：预激活 z 为输入加权和、循环隐状态项与偏置之和，输出按 softplus(z)=log(1+exp(z)) 计算（z 为正时改用稳定等价形式 z+log(1+exp(-z))，指数参数恒为非正，任意有限输入与参数都得到有限非负结果，极端 z 不会因指数中间量溢出而泄漏 OverflowError 或污染状态，z 趋负无穷时饱和为精确的 0），反向局部导数为 sigmoid(z)=1/(1+exp(-z))，由缓存输出经 1-exp(-output) 稳定求得；其导出状态的 kind 固定为 SoftplusSequenceState，仅与 TanhSequenceState、SigmoidSequenceState 区分且只接受同类、宽度相容的实例迁移（结构错误、外部类状态、非有限数字、尺寸不符抛 ValueError，无缓存反向或未结束流抛 RuntimeError，失败均不改变隐藏状态、输出、Linear 缓存、参数或梯度），其余非法参数、数值稳定性与失败原子性规则与 TanhSequence 完全一致。在此之上，ReLUSequence 作为第四种序列单元提供与 TanhSequence 完全同形的公开接口（forward/step/start_stream/finish_stream/backward/backward_with_initial_hidden/backward_with_boundaries、checkpoint/restore、export_state/import_state），沿用 Linear 前 d 个输入权重加最后一个循环权重的布局与全部截断、carry_hidden、initial_hidden、segment_starts 规则：预激活 z 为输入加权和、循环隐状态项与偏置之和，输出按 relu(z)=max(0,z) 计算（z≤0 时输出精确为 0，z>0 时输出等于 z，任意有限输入都得到有限非负结果，不存在溢出路径），反向局部导数在缓存输出为 0 时取 0、输出为正时取 1；其导出状态的 kind 固定为 ReLUSequenceState，与既有各类的 kind 标记区分且只接受同类、宽度相容的实例迁移（结构错误、外部类状态、非有限数字、尺寸不符抛 ValueError，无缓存反向或未结束流抛 RuntimeError，失败均不改变隐藏状态、输出、Linear 缓存、参数或梯度），其余非法参数、数值稳定性与失败原子性规则与 TanhSequence 完全一致。在此之上，LeakyReLUSequence 作为第五种序列单元提供与 TanhSequence 完全同形的公开接口（forward/step/start_stream/finish_stream/backward/backward_with_initial_hidden/backward_with_boundaries、checkpoint/restore、export_state/import_state），沿用 Linear 前 d 个输入权重加最后一个循环权重的布局与全部截断、carry_hidden、initial_hidden、segment_starts 规则：预激活 z 为输入加权和、循环隐状态项与偏置之和，输出按 leaky_relu(z) 计算（负斜率固定为 0.01，构造时只接收一个至少含两个权重的 Linear，不接受额外的可变斜率配置；z>0 时输出等于 z，z=0 时输出精确为 0.0，z<0 时输出为 0.01*z，任意有限输入、参数与隐状态都得到有限结果，不存在溢出路径），反向局部导数在缓存输出为正时取 1.0、输出小于或等于零时取 0.01；其导出状态的 kind 固定为 LeakyReLUSequenceState，与既有各类的 kind 标记区分且只接受同类、宽度相容的实例迁移（结构错误、外部类状态、非有限数字、尺寸不符抛 ValueError，无缓存反向或未结束流抛 RuntimeError，失败均不改变隐藏状态、输出、Linear 缓存、参数或梯度），其余非法参数、数值稳定性与失败原子性规则与 TanhSequence 完全一致。在此之上，GELUSequence 作为第六种序列单元提供与 TanhSequence 完全同形的公开接口（forward/step/start_stream/finish_stream/backward/backward_with_initial_hidden/backward_with_boundaries、checkpoint/restore、export_state/import_state），沿用 Linear 前 d 个输入权重加最后一个循环权重的布局与全部截断、carry_hidden、initial_hidden、segment_starts 规则：预激活 z 为输入加权和、循环隐状态项与偏置之和，输出按精确误差函数形式 gelu(z)=0.5*z*(1+erf(z/sqrt(2))) 计算（z=0 时输出精确为 0.0，任意有限 z 都得到有限结果，极端正负 z 不因指数或乘法溢出而抛出 OverflowError 或产生 NaN、无穷大），反向局部导数为 0.5*(1+erf(z/sqrt(2)))+z*exp(-z*z/2)/sqrt(2*pi)，由轨迹中逐步记录的预激活求得（GELU 非单调，无法仅从输出恢复 z），接近零时保持公式精度；其导出状态的 kind 固定为 GELUSequenceState，与既有各类的 kind 标记区分且只接受同类、宽度相容的实例迁移（结构错误、外部类状态、非有限数字、尺寸不符抛 ValueError，无缓存反向或未结束流抛 RuntimeError，失败均不改变隐藏状态、输出、Linear 缓存、参数或梯度），其余非法参数、数值稳定性与失败原子性规则与 TanhSequence 完全一致。
